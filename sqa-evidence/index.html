This dashboard is only the evidence viewer on http://localhost:8088. Playwright tests the real Vite app on http://127.0.0.1:5173, so the two-server setup is expected.
  • node sqa-evidence\scripts\run-frontend-checks.mjs refreshes static/build evidence.
  • node sqa-evidence\scripts\run-playwright-ui.mjs runs fast headless browser checks.
  • node sqa-evidence\scripts\run-playwright-ui.mjs --headed --record --slow opens the browser, slows actions down, and saves video/trace in the Playwright HTML report.
  • node sqa-evidence\scripts\run-all-checks.mjs runs frontend checks and Playwright UI checks in one command.
